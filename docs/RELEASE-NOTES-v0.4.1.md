# W.A.C.K. v0.4.1 - Public browser release

[Play the game](https://peteconnorctg.github.io/wack-strategic-command/) · [Read the Player's Handbook](https://peteconnorctg.github.io/wack-strategic-command/docs/WACK-Players-Handbook.pdf)

An original single-player Cold War command-room strategy game. Investigate conflicting reports, weigh staff advice, and issue orders that shape the crisis.

## Included

- Six command rooms for decisions, evidence, staff advice, response packages, approval checks, and the campaign record.
- Reviewed orders and release-authorization checks.
- Exchange playback with pause, event stepping, and replay controls.
- Browser-local saving and a resume briefing.
- An illustrated, vintage-style player handbook with a guided first decision.

## Before you play

No account or installation is required. Saves remain in the same browser on the same website; they do not sync between devices. Avoid private browsing, and wait for the saved confirmation before closing. Clearing site data can remove progress.

This release labels the existing deployed v0.4.1 game and adds its public documentation and reporting path. It does not change gameplay or migrate saves. GitHub's automatically generated source archives contain this compiled distribution repository, not the private development source.
