# W.A.C.K. — Strategic Command System

Playable browser distribution of an original single-player command-room strategy game.

Saves are stored locally in this browser for this website. They do not automatically transfer from localhost, another website, browser, or device. Clearing browser site data can remove saves.

This repository contains compiled distribution files, not the source development repository. Browser-delivered code and content are publicly inspectable.
